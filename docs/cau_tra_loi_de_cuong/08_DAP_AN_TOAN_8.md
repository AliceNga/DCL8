## ĐỀ SỐ 1

### Bài I (2,0 điểm): Thực hiện phép tính và thu gọn
- **a)** $(3x^2y - 2xy) + (x^2y + 5xy) = (3x^2y + x^2y) + (-2xy + 5xy) = 4x^2y + 3xy$.
- **b)** $(6x^3y^2 - 9x^2y^3):(3xy) - (2x^2y + 3xy^2) = (2x^2y - 3xy^2) - (2x^2y + 3xy^2) = -6xy^2$.
- **c)** $(2x - y)^2 + (x + y)(x - y) = (4x^2 - 4xy + y^2) + (x^2 - y^2) = 5x^2 - 4xy$.
- **d)** $(x - 1)(x^2 + x + 1) - (x + 1)^3 = (x^3 - 1) - (x^3 + 3x^2 + 3x + 1) = -3x^2 - 3x - 2$.

### Bài II (2,0 điểm): Toán thực tế khuôn viên và hồ bơi
- **a)** Biểu thức diện tích trồng cỏ:  
  $S_{khuôn viên} = (x + 4)(y + 2) = xy + 2x + 4y + 8$  
  $S_{hồ bơi} = xy$  
  $\Rightarrow A = S_{khuôn viên} - S_{hồ bơi} = 2x + 4y + 8$ ($m^2$).
- **b)** Tổng chi phí trồng cỏ:  
  $B = 150\,000 \times A = 150\,000(2x + 4y + 8) = 300\,000x + 600\,000y + 1\,200\,000$ (đồng).
- **c)** Với $x = 12$ và $y = 8$:  
  $A = 2(12) + 4(8) + 8 = 24 + 32 + 8 = 64$ $m^2$.  
  $B = 64 \times 150\,000 = 9\,600\,000$ (đồng).

### Bài III (2,0 điểm): Tìm x
- **a)** $2x^2 + 4x = 0 \Leftrightarrow 2x(x + 2) = 0 \Rightarrow x = 0$ hoặc $x = -2$.
- **b)** $(2x + 1)^2 - x^2 = 0 \Leftrightarrow (2x + 1 - x)(2x + 1 + x) = 0 \Leftrightarrow (x + 1)(3x + 1) = 0 \Rightarrow x = -1$ hoặc $x = -\frac{1}{3}$.
- **c)** $3x - 3 + x^2 - 1 = 0 \Leftrightarrow 3(x - 1) + (x - 1)(x + 1) = 0 \Leftrightarrow (x - 1)(x + 4) = 0 \Rightarrow x = 1$ hoặc $x = -4$.
- **d)** $(x + 2)(x^2 - 2x + 4) - 2x(x + 2) = 0 \Leftrightarrow (x^3 + 8) - (2x^2 + 4x) = 0 \Leftrightarrow (x + 2)(x^2 - 4x + 4) = 0 \Leftrightarrow (x + 2)(x - 2)^2 = 0 \Rightarrow x = -2$ hoặc $x = 2$.

### Bài IV (3,5 điểm): Hình học tam giác cân và hình bình hành
- **a)** Tam giác $ABC$ cân tại $A \Rightarrow \widehat{B} = \widehat{C}$. Vì $MN // BC \Rightarrow BMNC$ là hình thang; có hai góc kề đáy bằng nhau nên $BMNC$ là **hình thang cân**.
- **b)** $N$ là trung điểm $AC$ và $NM = NE \Rightarrow AECM$ có hai đường chéo cắt nhau tại trung điểm mỗi đường nên là **hình bình hành**.  
  Vì $MN // BC$ và $ME = 2MN = BC \Rightarrow BMEC$ có cặp cạnh đối song song và bằng nhau nên là **hình bình hành**.
- **c)** $\Delta CNE$ cân tại $N$; $G$ là trọng tâm $\Delta ABC \Rightarrow GM = \frac{1}{3}BN$.

### Bài V (0,5 điểm): Sức mạnh đoàn kết
- **a)** Chu vi hình vuông 1 là $4xa \Rightarrow$ cạnh là $xa \Rightarrow S_1 = (xa)^2 = x^2 a^2$.  
  Chu vi hình vuông 2 là $4ya \Rightarrow$ cạnh là $ya \Rightarrow S_2 = y^2 a^2$.  
  Tổng diện tích: $S_1 + S_2 = (x^2 + y^2)a^2$.  
  Gộp cả 2 bó đũa được $(4x + 4y)$ chiếc $\Rightarrow$ cạnh hình vuông lớn là $(x + y)a \Rightarrow S_{lớn} = (x + y)^2 a^2 = (x^2 + 2xy + y^2)a^2$.  
  Vì $x, y > 0 \Rightarrow 2xy a^2 > 0 \Rightarrow S_{lớn} > S_1 + S_2$.  
  *Ý nghĩa:* Khi hợp lực đoàn kết, sức mạnh tạo ra lớn hơn tổng đơn thuần của từng cá nhân riêng lẻ.
- **b)** $S_{lớn} = 2(S_1 + S_2) \Leftrightarrow (x + y)^2 = 2(x^2 + y^2) \Leftrightarrow x^2 - 2xy + y^2 = 0 \Leftrightarrow (x - y)^2 = 0 \Leftrightarrow x = y$.  
  Số đũa hai bó bằng nhau.

## ĐỀ SỐ 2, 3, 4 (TÓM TẮT TRỌNG TÂM)
- **Đề 2 - Bài V (Bãi cỏ bên bờ sông):** Gọi chiều rộng là $x$ ($m$). Chiều dài là $100 - 2x$. $S = x(100 - 2x) = -2(x - 25)^2 + 1250 \le 1250$. Diện tích lớn nhất là $1250\,m^2$ khi $x = 25\,m$.
- **Đề 3 - Bài V (Tối ưu lợi nhuận bán bút):** Gọi giá giảm là $k$ (nghìn). Lợi nhuận $P(k) = (20 - k)(50 + 5k) = -5(k - 5)^2 + 1125 \le 1125$. Nên bán với giá $35\,000$ đồng để lợi nhuận lớn nhất là $1\,125\,000$ đồng/ngày.
- **Đề 4 - Bài V (Uốn dây thép 24m):** Chia dây để tổng diện tích nhỏ nhất: bài toán cực trị bậc hai đạt cực tiểu khi cạnh hình vuông và hình chữ nhật thỏa mãn đạo hàm bằng 0.
